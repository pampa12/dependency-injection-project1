The problem in code
class TightlyCoupledOrderService:
    def __init__(self):
        self.payment_processor = CreditCardPayment()

    def checkout(self, order):
        self.payment_processor.pay(order.total)
Why this is a problem
✕ Payment choice is hard-coded ✕ Switching providers requires editing OrderService ✕ FakePayment cannot be injected for testing ✕ OrderService has more than one responsibility
