Dependency Injection Demo

Pick a payment method, then run both versions and compare the result.

Without DI

OrderService creates CreditCardPayment inside itself. 

self.payment_processor = CreditCardPayment()
Ready.

With DI

The payment object is created outside and passed into OrderService. 

payment = CreditCardPayment("1234")
service = OrderService(payment)
Ready.
Main point: Without DI, changing the payment method means changing OrderService. With DI, we only change the object we pass in.
